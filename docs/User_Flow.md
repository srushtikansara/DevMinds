# User Flow

## Overview

The platform captures developer interactions from AI tools, processes them asynchronously, builds long-term memory, updates the developer profile, and generates personalized insights.

---

## User Journey

Developer
↓
Connect Claude Code
↓
AI Coding Session
↓
Session Uploaded
↓
Session Processing
↓
Developer Events Extracted
↓
Memory Created
↓
Developer Profile Updated
↓
Recommendations Generated
↓
Weekly Report Generated
↓
Dashboard

---

## MVP Flow

1. Connect Claude Code
2. Upload AI session
3. Process session
4. Store memory
5. Update developer profile
6. Generate report
7. Search previous memories
